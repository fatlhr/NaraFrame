# Paper Cutout

Use the attached brief and the character workflow in the sibling `naraframe/characters.md`. Select profile `paper-cutout@0.1.0` and the matching catalog at `library/characters/paper-cutout/catalog.json` inside the engine.

Layer cut edges and offset shadows in a fixed overhead view. Move rigid paper pieces through short turns about a visible hinge, with a held pose between actions. Use `paper-bridge@0.1.0` when a hinged bridge fits the story. For a different object, stage an original shot with the same rhythm.
