# Bedah 2.5D

Use the brief and the character workflow in the sibling `naraframe/characters.md`. Select `bedah-25d@0.1.0` and the matching catalog at `library/characters/bedah-25d/catalog.json` inside the engine.

Show the object in use, separate its illustrated parts in a fixed projection, hold each part long enough to explain its function, then reassemble it and show it working. Use `tape-dispenser@0.1.0` or `flashlight@0.1.0` for the matching subject. Draw original layers for other objects. Keep free camera orbits and mesh geometry outside this workflow.
